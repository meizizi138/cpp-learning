# 第 4 周笔记：函数与引用传递

## 1. 函数是什么

函数相当于一个小工具箱，打包一堆代码可以直接用。
以后用起来，函数里面的功能更简洁。

函数解决三个问题：避免重复、便于修改、便于阅读。

## 2. 值传递 vs 引用传递

- 值传递：函数拿到的是副本（把值复制一份给函数）
- 引用传递：函数拿到的是变量本身

所以值传递不改变根本数据，引用传递会在外改变。

## 3. 比喻

- 值传递 = 在手上画画，洗掉就没了，皮肤没变
- 引用传递 = 直接更改皮肤，洗不掉，人真的变了

## 4. 什么时候用 &

- 在函数里改变外界，必须用
- 不该用：只在函数里暂时借用，不想影响本质
- 最实用的场景：return 只能带回一个结果，& 可以带回任意多个

例子（同时拿到商和余数）：

```cpp
void divmod(int a, int b, int& q, int& r) {
    q = a / b;
    r = a % b;
}
```

## 5. 代码例子

```cpp
#include <iostream>
using namespace std;

void swapWrong(int a, int b) {        // 值传递
    int t = a; a = b; b = t;
}

void swapRight(int& a, int& b) {      // 引用传递
    int t = a; a = b; b = t;
}

int main() {
    int p = 1, q = 2;

    swapWrong(p, q);
    cout << "值传递后：p = " << p << ", q = " << q << endl;

    swapRight(p, q);
    cout << "引用传递后：p = " << p << ", q = " << q << endl;
}
```

运行结果：

```
值传递后：p = 1, q = 2
引用传递后：p = 2, q = 1
```

值传递那次没换成功，因为函数里交换的是副本。
引用传递那次成功了，因为 & 让函数直接操作 p 和 q 本身。
